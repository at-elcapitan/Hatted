# Hatted

A universal assistant for the host of the Sport Mafia game on iOS.

## Requirements

- iPhone running iOS 26 or later
- macOS Sequoia and Xcode 26 or later to build the app
- Git
- An Apple account for code signing

## Installation

### Build and run

1. Install Xcode from the App Store or download it from [developer.apple.com](https://developer.apple.com/download/). Install the Xcode Command Line Tools if prompted
2. Clone the repository:

```bash
git clone https://github.com/at-elcapitan/Hatted.git
```

3. Open the cloned project in Xcode
4. In the project’s **Signing & Capabilities** settings, select your development team signature
5. Enable Developer Mode on your iPhone. See instructions at [developer.apple.com](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)
6. Connect your iPhone, select it as the run destination, and click **Run**
